# 怎麼操作
* 點一下畫面：顯示下一句。字還在跑的時候點一下，會直接顯示整句。
* 長按畫面：快轉，放開就停。遇到章節最後一句會自動停下。
* 回顧 ▲：打開這一章到目前為止的對話紀錄。
* ♪：開關背景音樂。
* 自動：自動播放下一句。
* 重來：從這一章的第一句重新開始。
* ‹ 章節：回到章節頁。閱讀進度會記在這台裝置的瀏覽器裡，下次可以接著看。
用手機直式觀看效果最好，iPhone 請關閉靜音模式才聽得到音樂。用電腦觀看時，即使切換畫面也能聽bgm。
